# SAYLESS typefaces

Self-hosted WOFF2 files obtained from the official Fontshare font API for the typefaces specified in design.md.

- Chubbo Bold (700): https://www.fontshare.com/fonts/chubbo
- Supreme Regular/Medium/Bold (400/500/700): https://www.fontshare.com/fonts/supreme

CSS definitions: apps/web/src/sayless.css. The original per-mood typefaces remain available through the existing Google Fonts stylesheet.

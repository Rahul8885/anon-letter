# Physical correspondence study

Open `index.html` directly in a browser, or serve this folder with a static HTTP server. No build step, package installation, or application backend is required. Google Fonts loads the existing brand typefaces when online; local font fallbacks keep the prototype usable offline.

## Review

Choose one of the five envelopes, then use **Sealed**, **Opened**, **A glimpse**, and **Read** to inspect the sequence. The main button advances through the same states. The full sheet remains live, selectable HTML text; the envelope stays on the table when the letter is extracted. Reduced motion switches states immediately. Without JavaScript, the default Old Letter is shown fully extracted.

This is the visual approval artifact requested in the September 15 brief. It does not change the production React app, send letters, contact the API, or implement drag physics, Three.js, or React Three Fiber. The future ribbon, seal, thread, band, and tape gestures are represented by static states and simple CSS transitions.

## Materials

All five envelope photographs and the cotton-paper sheet were generated using the built-in imagegen tool. The prototype shares the optimized WebP files in `apps/web/public/assets/letter-world`, preserving transparency without duplicate PNG sources. Generation prompts and metadata were removed during repository cleanup.

Object presentation was informed by [Trevor Noah — Books](https://www.trevornoah.com/books), especially freestanding scale and depth. AnonLetter's existing palettes, font families, room names, and sample letters were retained.

The photos are concept artwork, not photographs of manufactured stationery. Each opening is a visual mock state; detailed closure mechanics and final material engineering await approval.
